\# Distributed Order Processing System



An event-driven distributed order processing system built using Python, FastAPI, Apache Kafka, PostgreSQL, Docker, and Docker Compose.



\## Architecture



The system consists of independently deployable microservices that communicate asynchronously through Apache Kafka.



\## Services



\- Order Service

\- Payment Service

\- Inventory Service

\- Notification Service



\## Technology Stack



\- Python

\- FastAPI

\- Apache Kafka

\- PostgreSQL

\- Docker

\- Docker Compose

\- Prometheus

\- Grafana
